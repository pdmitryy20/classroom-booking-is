# ІС «Бронювання аудиторій»

Навчальний проєкт веб-сервісу для бронювання навчальних аудиторій університету.

## Архітектура

- **Frontend:** веб-застосунок (React)
- **Backend:** REST API (Node.js, Express)
- **База даних:** PostgreSQL
- **Авторизація:** OAuth 2.0 через університетську пошту
- **Сповіщення:** e-mail сервіс

## Ролі користувачів

1. Студент — переглядає вільні аудиторії та бронює їх
2. Викладач — бронює аудиторії та експортує їх у календар
3. Адміністратор — підтверджує заявки та керує списком аудиторій

## Управління проєктом

Задачі ведуться в GitHub Issues та на Kanban-дошці GitHub Projects.
